FC FILMWERKS – HOMEPAGE DESIGN GUIDELINES
=========================================
Stack: Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion
Tailwind v4 is CSS-first. There is no tailwind.config.ts — tokens live in src/app/globals.css.


1. LAYOUT
---------
Max container width      None. Homepage sections are full-bleed.
                         Wrapper is: w-full + horizontal padding (below).
                         (A <Container> component exists with max-w presets but
                         is NOT used by homepage sections.)

Page padding – Desktop   3vw   (fluid, from 768px up)
Page padding – Tablet    3vw   (same token, ≥768px)
Page padding – Mobile    16px  (1rem)

Section spacing          Mobile   top 64px  / bottom 80px
                         Tablet   top 80px  / bottom 96px
                         Desktop  top 96px  / bottom 112px

Grid / card gaps         Services carousel   20px → 24px (md)
                         Featured Work grid  40px
                         Client logo grid    16px → 20px (md)
                         Header ↔ grid       64px → 96px (lg)

Border radius            48px   footer card (md+)
                         28px   intro frame, footer card (mobile), menu panel
                         24px   service + project cards
                         16px   client logo tiles (rounded-2xl)
                         Full   all buttons (rounded-full)
                         2px    global --radius token (base UI default)

6. MOTION
---------
Easing (Framer)    out    cubic-bezier(0.16, 1, 0.3, 1)     default UI
                   expo   cubic-bezier(0.19, 1, 0.22, 1)    cinematic settle
                   inOut  cubic-bezier(0.65, 0, 0.35, 1)
Easing (GSAP)      power3.out · power2.inOut · expo.out

Durations          fast 0.3s · base 0.6s · slow 0.9s · slower 1.4s
                   Section reveals in practice: 0.8s–0.9s

Scroll reveal      Framer whileInView · viewport { once: true, amount: 0.1–0.6 }
                   Standard: opacity 0→1, translateY 32–40px→0
                   Cards: + scale 0.96→1, blur 5px→0
                   Stagger: 0.05 / 0.08 / 0.10 / 0.12 between siblings

Parallax           Scroll-driven (useScroll + useTransform), 24–60px travel.
                   Image wrappers must be overscanned beyond the travel distance.

Hover transitions  300ms  colour only (buttons base)
                   500ms  borders, links, logo scale
                   600ms  card transform + shadow
                   700ms  image zoom

RULES
  - One transform per element. Framer writes `transform` wholesale; two
    animations on one node silently overwrite each other. Nest wrappers.
  - Never use a mask/clip that starts closed for required content — a missed
    trigger hides it permanently. Use scroll-driven motion values instead.
  - Respect prefers-reduced-motion: collapse to opacity-only fades.
  - Import GSAP from @/lib/gsap only. Every GSAP effect must clean up.


7. RESPONSIVE BREAKPOINTS
-------------------------
Tailwind v4 defaults — not overridden.

  Mobile     < 768px          base styles
  Tablet     ≥ 768px   (md)   gutters switch to 3vw
  Laptop     ≥ 1024px  (lg)   3-column grids, largest type step
  Desktop    ≥ 1280px  (xl)   final display sizes
  Wide       ≥ 1536px  (2xl)  available, sparingly used

  (sm ≥ 640px exists but is not used on the homepage.)


8. NOTES
--------
- Maintain consistent spacing throughout the homepage. Every section uses the
  same rhythm: px-4 md:px-[3vw] gutters, pt-16/pb-20 → lg:pt-24/pb-28.
- Keep all sections visually aligned. Section headers share one pattern:
  gold uppercase label → large uppercase H2 → right-aligned standfirst.
- Preserve the cinematic premium aesthetic: dark grounds, gold as accent only,
  film grain and vignette overlays, generous whitespace, slow understated motion.
- Colour comes from tokens where they exist (bg-background, text-muted,
  border-border, bg-accent). Section-specific literals are listed in §3.
- The intro, lens transition and footer are coupled by scroll geometry
  (sticky wrappers + negative margins). Do not change one in isolation —
  see the comments in IntroExperience.tsx, LensTransition.tsx and
  CinematicFooter.tsx before adjusting heights or margins.
